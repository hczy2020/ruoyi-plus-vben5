## 使用方法

注意：以下操作均是在后端代码中完成（即在IDEA中）

解压收到的模板压缩包：

1、将 vben5 文件夹复制到 ruoyi-modules/ruoyi-generator/src/main/resources/vm/ 下。

2、替换 ruoyi-modules/ruoyi-generator/src/main/java/org/dromara/generator/util/VelocityUtils.java 文件。

3、重启服务即可。
